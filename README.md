# 스마트 발매트를 활용한 고령자 위험 상황 자동 통보 시스템

독거노인의 **낙상·응급 상황을 조기에 감지**하고, 관리자(지자체·복지기관)가 실시간으로 확인·대응할 수 있게 하는 시스템입니다.
화장실 앞 등에 설치한 **스마트 발매트(압력 센서)** 가 출입·체류를 감지하고, 일정 시간 이상 움직임이 없으면 응급 상황으로 판단해 자동으로 알립니다.

> 2025학년도 1학기 바이오메디컬 캡스톤디자인 · **캡스톤 4조**
>
> **이 저장소는 시스템 중 "관리자 웹 대시보드" 부분입니다.** (하드웨어/펌웨어 제외)

---

## 배경 (필요성)

- 고령화·1인 가구 증가로 독거노인의 고독사가 사회 문제로 대두되고 있습니다.
- 고령자 안전사고의 **62.7%가 낙상**이며, 그중 **74%가 주택 내(특히 화장실·욕실)** 에서 발생합니다.
- 노인은 응급 상황에서 스스로 구조 요청을 하기 어려워 골든타임을 놓치는 경우가 많습니다.
- 이에 **설치가 간편하고 특정 위치의 이상을 빠르게 감지**하는 발매트형 감지 장치를 제안합니다.

---

## 시스템 전체 구성

```
[스마트 발매트 + 압력센서]
        │  (밟힘 감지)
        ▼
[아두이노 ESP32]  ── 상태값(status) 계산, LED·부저 피드백
        │  (실시간 전송)
        ▼
[Firebase Realtime Database]  ── 아두이노·웹이 공유하는 중앙 데이터베이스
        │
        ▼
[JavaScript]  ── Firebase 데이터를 받아 웹 화면에 반영
        │
        ▼
[HTML + CSS]  ── 관리자용 대시보드 화면
        │
        ▼
[GitHub]  ── 웹사이트 배포(제3자도 접속 가능한 주소 제공)
```

이 저장소는 위 흐름에서 **Firebase → JavaScript → HTML/CSS** 에 해당하는 관리자 웹입니다.

## 상태값(status) 정의

센서의 상태는 아두이노에서 계산되어 Firebase로 전달됩니다.

| status | 의미 | LED | 부저 | 웹 표시 |
|:---:|---|:---:|:---:|---|
| **0** | 발판을 밟지 않은 평상 상태 | 🟢 초록 | 없음 | 전체 센서 |
| **1** | 발판을 밟은 직후 (화장실 진입) | 🟡 노랑 | 없음 | 전체 센서 |
| **2** | 장시간 반응 없음 → **응급 상황** | 🔴 빨강 | 울림 | **긴급 센서 (빨강 강조 + 알람)** |

**시간 조건 (아두이노에서 판단)**
- status `0` 이 **24시간 이상** 유지되면 → `2` 로 변경
- status `1` 에서 **1시간 30분 이상** 다시 밟히지 않으면 → `2` 로 변경
- status `2` 상태에서 오작동이었을 경우, 패드를 한 번 더 밟거나 웹의 **경고 해제** 버튼을 누르면 → `0` 으로 복귀

## 웹 대시보드 주요 기능

- **긴급 / 전체 센서 분리** — status `2`(응급)가 되면 자동으로 "긴급 센서" 영역으로 올라오며, 창을 빨간색으로 강조
- **실시간 반영** — Firebase 값이 바뀌면 새로고침 없이 화면이 즉시 갱신
- **지역별 분류·검색** — 좌측 사이드바에서 시/도 → 시/군/구 → 동 단계로 선택해 해당 지역 사용자만 조회 (기기마다 주소지 지정)
- **경고 해제(리셋)** — 응급이 오작동이었을 때 관리자가 상태값을 `0` 으로 되돌림
- **알람** — status `2` 발생 시 소리로도 알림 (기기별 음량 on/off 예정)
- **일별 통계 그래프** — 카드의 "감지 횟수 평균값"을 클릭하면 날짜별 감지 추이 확인 (Chart.js)

## 실행 방법

ES 모듈과 `fetch()` 를 사용하므로 **HTML 파일을 더블클릭하면 동작하지 않습니다.** 로컬 웹 서버로 실행하세요.

### Python (설치 없이 바로)

```bash
cd BiomedicalCapstone
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/2025.6.16.html` 접속. 종료는 `Ctrl + C`.

### VS Code Live Server

`Live Server` 확장 설치 후 `2025.6.16.html` 우클릭 → **Open with Live Server**

## 처음 세팅 (Firebase 설정)

Firebase 설정은 `js/firebase-config.js` 에 두며, `.gitignore` 로 저장소에는 올리지 않습니다.
저장소를 새로 받았다면 아래로 설정 파일을 만드세요.

```bash
cp js/firebase-config.example.js js/firebase-config.js
```

이후 `js/firebase-config.js` 를 열어 본인 Firebase 프로젝트 값으로 채웁니다.
(Firebase 콘솔 → 프로젝트 설정 → 내 앱 → SDK 설정 및 구성)

## 데이터 구조 (Firebase Realtime Database)

```
/sensors/{기기ID}
  ├─ name              : 사용자 이름
  ├─ address           : 주소 (지역 분류·검색에 사용)
  ├─ phone             : 전화번호
  ├─ time              : 기상시간
  ├─ number            : 감지 횟수
  ├─ value             : 상태값 (0 / 1 / 2)
  ├─ averagePressCount : 감지 횟수 평균값
  └─ command           : 명령 (예: "reset")

/daily_stats/{날짜}/{기기ID}
  ├─ average           : 해당 날짜 평균 감지 횟수
  └─ pressCount        : 해당 날짜 총 감지 횟수
```

## 보안 참고

- Firebase 웹 `apiKey` 는 **비밀값이 아닙니다.** 웹 앱에 노출되도록 설계된 프로젝트 식별자라 숨긴다고 보안이 되지 않습니다.
- 실제 보안은 **Realtime Database 보안 규칙(Rules)** 으로 합니다. 규칙이 열려 있으면 누구나 데이터를 읽고 쓸 수 있으니 꼭 확인하세요. (Firebase 콘솔 → Realtime Database → 규칙)
